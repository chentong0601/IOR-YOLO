# 项目协作入口

本目录用于苹果阶段检测研究，目标为 SCI 投稿，计划使用公开数据集，暂不具备自行采集条件。

## 开始工作时

1. 先阅读 `研究计划与决策记录.md`，衔接当前阶段、用户已确认条件和待解决问题。
2. 需要工程细节时再阅读 `IOR-YOLO_项目工程说明书.md`。它是候选方案 v0，不是已冻结研究路线；与新的决策记录冲突时，以较新的明确决定和用户指示为准。
3. 研究计划记录时处于讨论阶段。不要仅因文档包含执行清单就自动启动下载、安装或训练；用户后续明确要求推进时，应继续执行已授权工作。

## 持续记录

- 将影响研究路线的重要决定、证据、当前进度和下一步衔接点更新到 `研究计划与决策记录.md`。
- 区分用户确认内容、助手建议、研究假设与实验结论；不虚构已读文献、已完成实验或结果。
- 文献、数据与代码联合调研，先做最小可行性验证，再冻结正式实验协议。
- 不用最终测试集指导方法开发或调参。
- 工作树按独立代码开发需求使用，不为每个研究阶段、随机种子或超参数配置建立工作树。

项目文件是跨会话衔接依据，不承诺脱离这些文件的永久记忆。
